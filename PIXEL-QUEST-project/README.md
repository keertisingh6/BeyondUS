# 🎮 PIXEL QUEST — 8-Bit Puzzle Engine

An authentic retro 8-bit puzzle expedition game built with React, TypeScript, Vite, and synthesized Web Audio API chiptunes.

---

## 🌟 Features
- **Authentic Chiptune Sound Engine**: Synthesized retro audio using Web Audio API (steps, safe discovery chime, coin ding, golden key fanfare, lethal trap crunch, shield deflect, radar scan, victory arpeggio, and optional background chiptune melody).
- **Tactile UI / UX**: Click-to-move adjacent tiles, directional player sprite facing, stone breadcrumb trails, animated shield aura, and board shake on impact.
- **3-Star Rating System**: Complete mazes with zero mistakes to earn ★★★ 3 Stars! Tracks best times, moves, and fewest mistakes.
- **Lifelines**:
  - `[1]` **Reveal**: Unveils the next safe tile.
  - `[2]` **Extra Life**: Arms an energy shield to forgive your next mistake.
  - `[3]` **Scanner**: Pings the next 3 path tiles on radar for 2 seconds.
- **Full-Screen Pixel Confetti**: Celebratory 8-bit celebration upon maze clearance.
- **Responsive Controls**: Full support for keyboard (`Arrows`, `WASD`, `HJKL`), mouse/touch clicking, and on-screen mobile D-pad.

---

## 🚀 How to Run

### Requirements
- [Node.js](https://nodejs.org/) (v18 or higher)

### Installation & Launch
1. Open PowerShell / Command Prompt in this folder.
2. Install dependencies (if not already installed):
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm run dev
   ```
4. Open the local URL in your browser (usually `http://localhost:5173`).
