# 🎮 Pixel Quest

**A retro pixel-art puzzle adventure where every step is a mystery.**

Pixel Quest is a hidden-path puzzle game in which players explore an unknown grid, discover safe tiles, avoid dangerous traps, collect bonus coins, find a golden key, and reach the exit. Each level introduces greater difficulty, encouraging players to think strategically and use their lifelines wisely.

## ✨ Features

- **Hidden-Path Gameplay:** Explore a grid where undiscovered tiles look identical.
- **Three Adventure Levels:** Progress through increasingly challenging stages.
- **Hidden Animal Traps:** Avoid dangerous animals hidden beneath unexplored tiles.
- **Golden Key Objective:** Find the key before reaching the exit.
- **Bonus Coins:** Collect hidden coins to earn extra points, while some rewards may conceal dangerous traps.
- **Special Lifelines:**
  - Reveal Tile — reveal a safe tile.
  - Extra Life — gain an additional life.
  - Path Scanner — temporarily reveal the next three safe tiles.
- **Level Roadmap:** Track progress and unlock levels sequentially.
- **Retro Pixel-Art Design:** A game interface inspired by classic pixel games.
- **Light Theme:** A warm cream background paired with navy tiles, muted teal discoveries, and gold accents.

## 🕹️ How to Play

1. Start the game and select an unlocked level.
2. Explore the grid by selecting tiles.
3. Remember discovered safe tiles and avoid dangerous traps.
4. Collect the golden key.
5. Collect bonus coins to increase your score.
6. Use your lifelines strategically.
7. Reach the exit with the key to complete the level.
8. Unlock the next level and continue your adventure.

**Be careful:** Ordinary wrong tiles cost lives, while hidden animal traps can end your run immediately.

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

Clone the repository:

```bash
git clone https://github.com/keertisingh6/pixel-quest.git
```

Navigate to the project directory:

```bash
cd pixel-quest
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to play the game.

### Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🎨 Design Philosophy

Pixel Quest combines the mystery of hidden-path puzzles with retro pixel-art visuals. Its interface uses a warm light theme, deep navy tiles, muted teal discovery states, and golden accents to keep gameplay clear while maintaining a nostalgic aesthetic.

The gameplay focuses on exploration, memory, risk, reward, and gradual progression.
